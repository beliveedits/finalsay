# Licences for the brand kit

## Fonts

**Atkinson Hyperlegible Next** and **Atkinson Hyperlegible Mono**
Copyright Braille Institute of America, Inc. Licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org).

How they are used here:

- The wordmark and all text in the logo and social SVG files are outlines of Atkinson Hyperlegible Next. Outlines need no font file and the OFL allows this use.
- `brand-guide.html` embeds the two variable font files so the page works offline. They come unmodified from the npm packages `@fontsource-variable/atkinson-hyperlegible-next` 5.3.0 and `@fontsource-variable/atkinson-hyperlegible-mono` 5.3.0, both published under OFL-1.1.
- No font file has been modified or renamed.

## Build tools (not shipped in the logo files)

- `opentype.js` 1.3.4, MIT licence. Used only to convert text to outlines when the SVG files are built.
- `@fontsource/atkinson-hyperlegible-next` 5.3.0 and `@fontsource/atkinson-hyperlegible-mono` 5.3.0, OFL-1.1. Source of the font files read by the build.
- `rsvg-convert` (librsvg, LGPL), used as a command-line program to render PNG files.
- Playwright (Apache-2.0) with Chrome, used to capture the three preview images from the board.
